# HUNRUTECH

A lightweight, dependency-free portfolio site for HUNRUTECH, built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static file server. No build step or package installation is required.

The projects section loads public, non-fork repositories from the GitHub API for `hunter-zen-RU`. The contact form opens a prefilled email draft in the visitor's default mail app; the recipient can be added before sending.

## Enable GitHub Pages

1. Push this repository to GitHub.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. After deployment completes, the site will be available at `https://hunrutech.github.io/`.
